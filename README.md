

**DevSecOps - Análise de Segurança**

Projeto desenvolvido para uma atividade com o objetivo de demonstrar a aplicação de práticas DevSecOps
e Shift Left em uma aplicação Web.


**Ferramentas utilizadas**

SonarQube - SAST
Snyk - SCA
OWASP ZAP - DAST


**Aplicação**

Aplicação desenvolvida com Node.js e Express.


**Objetivo**

Automatizar análises de segurança durante o processo de desenvolvimento, de maneira que vulnerabilidades sejam identificadas antes da aplicação chegar à produção.
